# Salvatore Rizzo - Bike Brake Kit
The product is a Motorcycle Brake Light kit that is copied from a similar product and tested by client to be working. The project scope involves creating a PCB that can be fabricated by the client.

## Project Requirements
- Develop a schematic design based on [this](https://github.com/eSpark-Consultants/salvatorerizzo-bikebrakekit/files/11941674/Scan2023-06-30_171441.pdf) circuit from client.
- The diodes in the pdf are SBDs 1N5822
- The connectors in the PDF are all same distinguished by number of pins. The hole size and pitch is defined in the image below.
- The mounting hole info and the board dimensions are defined in the image below.
